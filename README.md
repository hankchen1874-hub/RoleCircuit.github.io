# RoleCircuit website

The RoleCircuit marketing site, built with plain HTML, CSS, and JavaScript so it can deploy directly to GitHub Pages.

## Local preview

No dependencies are required. Serve the directory with any static server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Files

- `index.html`: marketing copy, product positioning, workflow, capabilities, and CTA
- `styles.css`: warm editorial visual system, responsive layout, and motion
- `script.js`: mobile navigation, workflow tabs, keyboard navigation, and scroll reveals
- `docs/exec-plans/2026-07-16-rolecircuit-website.md`: implementation plan and verification record
